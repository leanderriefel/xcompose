How it works

  1. Open X and click Post. The compose dialog appears.
  2. Under the text area you’ll see XCompose with Fix, Shorten, Punchier.
  3. Type your draft, hit a button. The draft is replaced in place — ↩ undoes.
  4. Use ▾ for more: Expand, Formal, Casual, Emojify.
ChatGPT account? XCompose is BYOK — use your API key. To use your ChatGPT Plus usage, bridge via OpenRouter (select OpenRouter and paste its key) or set Custom to any OpenAI-compatible proxy that forwards to ChatGPT. OpenCode Zen works the same: pick “OpenCode / Zen”, paste your Zen key, leave Base URL default.
